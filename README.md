# 연성중 내전

롤 내전 팀 편성, 판돈 정산, 솔랭 승패 내기와 배그 스팀 킬내기를 한곳에서 관리하는 웹 앱입니다. 배그 킬내기는 경기 전적을 주기적으로 확인해 새로 끝난 경기의 킬을 자동으로 누적합니다.

공개 사이트: https://yeonsung-lol-naejun.airplch.chatgpt.site

## 실행 방법

Node.js 18 이상이 필요합니다.

```bash
cd 내전
npm install
```

`.env.example`을 `.env`로 복사하고 Riot Developer Portal과 PUBG Developer Portal에서 발급한 API 키를 입력합니다.

```env
RIOT_API_KEY=RGAPI-your-api-key
RIOT_PLATFORM=kr
RIOT_REGION=asia
PUBG_API_KEY=your-pubg-api-key
PORT=3000
```

```bash
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 공유 내전방

- `새 방 만들기`를 누르면 현재 참가자, 팀 결과, 판돈, 경기 기록, 솔랭 점수와 배그 킬내기 기록이 들어간 6자리 방이 생성됩니다.
- 초대 링크를 보내거나 6자리 방 코드를 알려주면 친구들이 로그인 없이 같은 방을 볼 수 있습니다.
- 방을 만든 브라우저가 방장이 되며 참가자, 팀 편성, 승패, 정산과 솔랭 기록을 변경할 수 있습니다.
- 다른 참가자는 관전자로 입장하며 방장의 변경 내용이 약 3초 안에 자동으로 표시됩니다.
- 방장 권한 키는 방을 만든 브라우저에만 저장됩니다. 같은 브라우저에서 다시 입장하면 방장 권한이 복구됩니다.
- 공개 사이트의 공유방은 마지막 변경 후 30일 동안 유지됩니다.
- 로컬 Node.js 서버의 공유방은 개발용 메모리에 저장되므로 서버를 재시작하면 초기화됩니다.

## 팀 편성 방식

- 솔로 랭크의 티어, 단계, LP를 0~1,000점 범위의 점수로 환산합니다.
- 언랭크 플레이어는 150점으로 계산합니다.
- `자동 배정`은 가능한 모든 동일 인원 조합을 비교해 팀 점수 차가 가장 작은 결과를 선택합니다.
- 최적 결과가 여러 개면 그중 하나를 무작위로 선택합니다.
- `직접 배정`은 Blue/Red Team 칸에서 참가자를 한 명씩 선택해 원하는 팀으로 확정할 수 있습니다.
- 직접 배정에서도 양 팀 인원은 같아야 하며, 한 참가자를 두 팀에 중복해서 넣을 수 없습니다.
- 조합 계산량과 일반적인 내전 규모를 고려해 참가자는 최대 10명까지 등록할 수 있습니다.

## 판돈 정산 방식

- 판돈은 `1인당 금액`입니다. 1,000원을 입력하면 승리 팀원은 각자 1,000원을 따고 패배 팀원은 각자 1,000원을 잃습니다.
- 팀을 만든 뒤 Blue 또는 Red 승리를 선택하면 해당 경기의 팀 구성과 판돈이 기록됩니다.
- 개인별 승패, 딴 돈, 잃은 돈, 순손익을 누적해서 보여줍니다.
- 누적 순손익을 기준으로 `누가 누구에게 얼마를 보낼지` 송금 목록을 계산합니다.
- 잘못 기록한 경기는 마지막 기록부터 취소할 수 있고 전체 정산 기록도 초기화할 수 있습니다.
- 참가자와 경기 기록은 현재 브라우저에 저장됩니다. 브라우저 데이터를 지우거나 다른 기기에서 접속하면 기록이 이어지지 않습니다.

## 솔랭 내기 방식

- 등록된 참가자의 최근 솔로 랭크 경기 10개를 Riot Match-V5 API에서 가져옵니다.
- 새로 확인된 승리는 `+1`, 패배는 `-1`로 개인 점수에 누적합니다.
- 바로 이전 솔랭 경기와 같은 챔피언을 연속으로 사용한 경기는 자동으로 무효 처리하며 승패와 점수에 반영하지 않습니다.
- 같은 챔피언을 세 경기 이상 연속으로 사용하면 첫 경기만 유효하고 이후 연속 경기들은 모두 무효입니다.
- 이미 반영한 경기 ID를 저장해 같은 경기를 다시 동기화해도 점수가 중복으로 변하지 않습니다.
- 첫 동기화에서는 가져온 최근 경기들이 모두 반영되며, 이후에는 새 경기만 추가됩니다.
- 승리 수, 패배 수, 최근 경기와 현재 점수는 브라우저에 저장되고 `솔랭 기록 초기화`로 모두 지울 수 있습니다.
- 실제 전적 조회에는 서버의 `RIOT_API_KEY` 설정이 필요합니다.

## 배그 킬내기 방식

- Steam PUBG 닉네임으로 참가자를 최대 10명까지 등록할 수 있습니다.
- 킬내기 시간을 1~100시간으로 정하면 시작 이후 끝난 경기의 킬만 집계합니다.
- 진행 중에는 5분마다 전적을 자동 확인하며, 필요할 때 `전체 전적 동기화`로 바로 확인할 수도 있습니다.
- 경기 ID를 저장하므로 같은 전적을 여러 번 불러와도 킬이 중복으로 올라가지 않습니다.
- 누적 킬, 경기 수, 치킨 수와 최근 경기의 킬·순위·딜량을 순위표로 보여줍니다.
- 내기가 끝난 뒤 `최종 전적 집계`를 누르면 종료 시각 전에 끝난 경기까지만 반영합니다.
- 실제 전적 조회에는 서버의 `PUBG_API_KEY` 설정이 필요하며 API 키는 브라우저에 노출되지 않습니다.
